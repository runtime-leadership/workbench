# Knowledge

This directory belongs to the owner of a private Workbench. Use it for durable context that may help across conversations, reviews, decisions, and projects.

People and agents may create and update files here when useful. Keep project-specific working artifacts in `projects/`, and move only context worth retaining into `knowledge/`.

Add only information you are authorized to use. Do not store credentials, secrets, unnecessary personal data, or sensitive material that belongs in an approved company system.
