# Engineering 1:1

> Part of [Workbench by Runtime Leadership](https://github.com/runtime-leadership/workbench). Use this template on its own or in a private Workbench created from the GitHub template.

Use this shared document to prepare for and retain useful context from recurring 1:1s. These conversations should create space to celebrate wins, exchange feedback, discuss support and improvement, explore goals and longer-term growth, and strengthen the working relationship. Choose what matters now; you do not need to cover every area each week.

Keep the document in Google Docs or another shared text editor. Either person can add topics before the conversation. Add brief sub-bullets during or shortly after the conversation only when they preserve useful context, a decision, or follow-through.
